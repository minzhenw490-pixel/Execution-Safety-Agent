## 一、Week 4 最终产品方向

- 产品最终形态：一个**链上交易安全分析工具**，基于 Monad 测试链
- 核心流程：用户输入 Swap 参数 → 系统分析多链路由 → 输出风险评估 → 执行交易
- 定位：帮新人理解每笔交易的风险，帮成熟交易者做风险把控
- 不仅有安全检测，还有**教育意义**——让新人知道为什么这笔交易有风险

---

## 二、链上开发计划

- 使用 **Monad 测试链**（不是本地 Anvil），部署真实合约
- 部署多种测试代币：好币（如 USDT/USDC 模拟）+ 问题币（如可能 rug 的币）
- 部署多种交易池：正常池 + 有问题的池（如报价偏离、回滚风险）
- 在测试链上模拟真实数据波动，让 Demo 有说服力

---

## 三、前端 UI 设计方案

讨论了最终版页面布局：

| 位置 | 内容 |
|------|------|
| 🔹 **左上角** | 钱包连接按钮 + 连接状态 |
| 🔹 **左侧主区域** | 交易面板：选择货币对 → 输入金额 → 选银行/链路 → 执行 |
| 🔹 **中间/右侧** | 链路评分、风险评估、执行结果 |
| 🔹 **右下角** | AI 分析结果 / 解释窗口（可对话） |
| 🔹 **右上角** | 用户信息 + 成就/NFT 入口 |

**安全/不安全对比：** 在交易按钮处加一个「安全执行 / 直接执行」切换

**数据仪表盘：**
- 展示评分（环形图动画效果）
- 展示各链状态
- 不需要做复杂 K 线图，展示实时数据即可

## 四、AI 解释层讨论

- 风控参数的结果需要 **AI 解释**给用户看
- 解释为什么选这条路、为什么拒绝、为什么回滚
- 可用小模型（如千问）部署，对格式化参数解析效果不错
- 也可以先用规则模板，AI 解释作为可选项
