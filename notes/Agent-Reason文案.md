## ✅ ALLOW（放行）

| 情况 | 文案 |
|------|------|
| 正常通过 | ✅ 这条路没问题，放心走 |
| 过路费高 | ✅ 路是安全的，就是过路费贵了点 |
| 评分高 | ✅ 这条路靠谱，天天有人走 |

## ❌ REJECT（拦截）

### Pool Risk（池子问题）

| 情况 | 文案 |
|------|------|
| 报价虚高 | ❌ 这条路报价虚高，别光着往里冲 🛡️ |
| 报价比市场高 | ❌ 报价比正常市场贵了 5%，不对劲 |
| 失败率高 | ❌ 这条路 10 个人走 4 个翻车，咱换个走 |
| 池子太浅 | ❌ 池子里钱不够，进去容易滑一大跤 |
| 综合风险高 | ❌ 这条路坑太多，替你拦下来了 |

### Token Risk（代币问题）

| 情况 | 文案 |
|------|------|
| 合约权限异常 | ❌ 这个代币合约权限有问题，别碰 |
| 历史行为可疑 | ❌ 这个代币有可疑交易记录，建议避开 |
| 高风险标签 | ❌ 这个代币已被标记为高风险资产 |
| 诱骗型资产 | ❌ 这个代币看着像假的，大概率是诱骗资产 |
| 综合代币风险 | ❌ 代币本身有问题，已替你拦下来 |
