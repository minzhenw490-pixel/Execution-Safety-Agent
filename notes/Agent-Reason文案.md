# 🛡️ Agent Reason 文案定稿（大白话版）

> 所有文案原则：菜市场阿姨都能听懂。

---

## ✅ Route A — ALLOW（放行）

| 情况 | 文案 |
|------|------|
| 正常通过 | ✅ 这条路没问题，放心走 |
| Gas 略高 | ✅ 路是安全的，就是过路费贵了点 |
| 评分高 | ✅ 这条路靠谱，天天有人走 |

## ❌ Route B — REJECT（拦截）

| 情况 | 文案 |
|------|------|
| 报价虚高 | ❌ 这条路报价虚高，别光着往里冲 🛡️ |
| 失败率高 | ❌ 这条路 10 个人走 4 个翻车，咱换个走 |
| 池子没啥钱 | ❌ 池子里钱不够，进去容易滑一大跤 |
| 合约没穿衣服 | ❌ 这合约没穿衣服就跑出来了，先别碰 |
| 这家给的价不对 | ❌ 这家给的价比别人少，别去 |
| 综合风险高 | ❌ 这条路坑太多，替你拦下来了 |

## ⚠️ Route C — FALLBACK（降级）

| 情况 | 文案 |
|------|------|
| 自动切安全路径 | ⚠️ 前面有坑，已帮你拐到安全路线 ✅ |
| 推荐替代路径 | ⚠️ 换 Route A 吧，能多拿 39 USDC |
| 部分风险 | ⚠️ 这条路有点悬，但还有救，给你换条好的 |

| 原来的说法 | 大白话版 |
|-----------|---------|

| 告警 | 有问题 |
| 里程碑 | 成就解锁 |
