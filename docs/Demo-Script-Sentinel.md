# 🎬 Demo Script — Sentinel for Safe Execution

> **时长：** 约 3 分钟  
> **形式：** 现场操作讲解  
> **面向：** Hackathon 评委 / 观众  
> **定位：** 给 DeFi 用户用的「交易安全助手」  
> **Slogan：** Don't trade naked. 🛡️  
> **版本：** v2.0（Week 4 黑客松版）

---

## 🎬 场景设定

```
用户：小明（普通 DeFi 用户）
目标：在 Monad 链上把 100 USDT 换成 USDC
状态：完全不知道哪个银行/链路是安全的
```

---

## 第一轮：没有 Sentinel ❌

> **约 40 秒**

**🎙️ 讲述：**
> 「这是小明。他想在 Monad 链上把 100 USDT 换成 USDC，于是打开了一个 DEX，随便选了个池子就点了 swap。」

**🖥️ 屏幕操作：**
- 打开 Sentinel 页面（暗色主题）
- 连接 MetaMask 钱包
- 输入 100 USDT → USDC，不勾选安全保护
- 点击「直接执行」

**🎙️ 讲述：**
> 「交易完成了……但他选到了一个**异常流动性池**。到手只有 97.8 USDC，比市场价少了 2.2%。还白花了 Gas。」

**🖥️ 屏幕显示：**
- 交易成功，但到账金额明显比预期少
- Dashboard 上出现一条告警：「该池报价偏离市场均值 2.3%」

**🎙️ 讲述：**
> 「问题是：**发交易之前，没人告诉他这池子有问题。**」

---

## 第二轮：有 Sentinel 保护 🛡️

> **约 90 秒**

**🎙️ 讲述：**
> 「现在，同样的 swap，小明打开了 Sentinel 的安全保护。」

**🖥️ 屏幕操作：**
- 勾选「🛡️ 安全保护」
- 同样输入 100 USDT → USDC

**🎙️ 讲述：**
> 「系统获取了多条候选链路，然后开始做安全检查——」

**🖥️ 屏幕逐步展示：**
```
左侧交易面板：
  货币对：USDT → USDC
  可选银行：[中国银行 ✅] [招商银行 ⚠️] [贵峰银行 ❌]
  可用链路：[Route A · 安全] [Route B · 风险] [Route C · 中等]
  评分：92 / 65 / 35

右侧 AI 分析窗口：
  🔍 风险分析：
  ✅ 中国银行 — 历史成功率 98%，流动性充足
  ❌ 招商银行 — 报价偏离 2.3%，建议避开
  ⚠️ 贵峰银行 — 流动性不足，需注意滑点
  
  💡 AI 建议：推荐走 Route A（中国银行），预期到账 100.2 USDC
```

**🎙️ 讲述：**
> 「Route A 报价正常，放行。Route B——就是刚才小明走的那条——Agent 检测到报价偏离了 2.3%，直接拦截了，并且在右侧用 AI 解释了原因。」

**🖥️ 点击「安全执行」→ 交易成功：**
```
✅ 执行成功
Tx: 0xabc...123
到账：100.2 USDC
节省对比：+2.4%（vs 无保护）
```

**🎙️ 讲述：**
> 「同样的金额，同样的目标。有 Sentinel 保护，到手 100.2 USDC；没有保护，只有 97.8 USDC。**差了 2.4%——不是因为价格波动，只是因为选错了银行。**」

## 技术亮点

| 模块 | 实现方式 |
|------|---------|
| 链 | Monad 测试链（真实链上数据） |
| 代币/池 | 自部署测试币 + 交易池 |
| 风控 | 规则引擎 evaluateRoute() + AI 解释层 |
| 前端 | React + Vite，支持浅色/深色主题 |
| 钱包 | MetaMask 连接 |
| 成就 | NFT 勋章墙（mock 数据） |
