## 🎬 场景设定

```
用户：小明
目标：把 100 USDC 换成 GOOD 代币
背景：Monad 测试链上有 3 个池子
        每个池子报价不一样
```

---

## 第一轮：没开保护 ❌

> **约 30 秒**

**🎙️：**
> 「小明想换点 GOOD 代币，随便选了个池子就冲了。」

**🖥️ 操作：**
- 打开页面，不勾选保护
- 输入 100 USDC → GOOD
- 点击「直接充」

**🖥️ 显示：**
- 到账：**97.8 GOOD**
- 弹出：「这条路池子太浅，滑了一大跤」

**🎙️：**
> 「到手少了 2.2%。问题是——发交易之前，没人告诉他这个池子有问题。」

---

## 第二轮：有保护 🛡️

> **约 2 分钟**

**🎙️：**
> 「同样的金额，这次打开 Sentinel。系统不是只看一条路——它把市面上 3 个池子都扫了一遍。」

**🖥️ 显示：**

```
📊 参考价（SAFE 池）：1 USDC = 1 GOOD

┌──── 候选路径 ──────────────────────────────────┐
│                                                  │
│  Route A · SAFE 池                               │
│  💰 到手：99.1 GOOD                             │
│  📉 滑点：0.4%                                  │
│  🛡️ 风险评分：12 · 低                          │
│  ✅ 无风险标签                                    │
│                                                  │
│  Route B · SHALLOW 池                            │
│  💰 到手：83.12 GOOD                            │
│  📉 滑点：16.8%                                 │
│  🛡️ 风险评分：55 · 中                          │
│  ⚠️ 标签：滑点过高                                │
│                                                  │
│  Route C · TOXIC 池                              │
│  💰 到手：104.8 GOOD ← 报价最高！               │
│  📉 滑点：3%                                     │
│  🛡️ 风险评分：88 · 高                          │
│  ❌ 标签：有毒池 / 报价异常                       │
│                                                  │
├──────────────────────────────────────────────────┤
│  ⭐ AI 建议：Route A（不选报价最高的）          │
│  理由：Route C 虽然给价高，但池子有问题          │
│──────────────────────────────────────────────────│
│  [ ✅ 就走这条！]                                 │
└──────────────────────────────────────────────────┘
```

**🎙️：**
> 「注意看——Route C 报价是最高的，104.8。但系统没选它。」
>
> 「因为 Agent 发现这个池子有问题——报价异常、历史可疑。报价高不等于安全。」
>
> **「最佳报价不等于最佳路线。」**
>
> 「Route A 虽然给的不是最高价，但它是最稳的。」

**🖥️ 点击「就走这条！」→ 成功：**

```
✅ 成了！
到账：99.1 GOOD
比没穿衣服多拿了：1.3%
```

**🎙️：**
> 「同样 100 USDC。有保护到账 99.1，没保护只有 97.8。不是运气问题——是你有没有人帮你扫坑。」
