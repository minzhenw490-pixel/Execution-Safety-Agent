# 🎬 Demo Script — Sentinel for Safe Execution

> **时长：** 约 3 分钟  
> **形式：** 开场小动画 + 现场操作讲解  
> **面向：** Hackathon 评委 / 观众  
> **定位：** 给 DeFi 小白用的「交易安全助手」  
> **Slogan：** Don't trade naked. 🛡️  
> **语言风格：** 全篇大白话，菜市场阿姨都能听懂  
> **版本：** v3.0（Week 4 黑客松版 · 大白话剧本杀版）

## 🎬 场景设定

```
用户：小明（普通 DeFi 小白）
目标：在 Monad 链上把 100 USDT 换成 USDC
状态：完全不知道哪个银行/链路是安全的
```

---

## 第一轮：没有 Sentinel ❌

> **约 30 秒**

**🎙️ 讲述：**
> 「现在我们回到小明。他今天想把手上的 100 USDT 换成 USDC，打开了一个 DEX，随便选了个池子就点了 swap。」

**🖥️ 屏幕操作：**
- 打开 Sentinel 页面
- 连接 MetaMask 钱包
- 输入 100 USDT → USDC，**不勾选安全保护**
- 点击「直接充」

**🎙️ 讲述：**
> 「交易完成了……但他选到了一个有问题的池子。」

**🖥️ 屏幕显示：**
- 到账：**97.8 USDC**（比预期少了）
- 弹出吐槽提示：「这条路报价虚高，亏了 2.2%」

**🎙️ 讲述：**
> 「到手少了 2.2%，还白花了手续费。问题是——**发交易之前，没人告诉他这池子有问题。**」

---

## 第二轮：有 Sentinel 保护 🛡️

> **约 90 秒**

**🎙️ 讲述：**
> 「同样的 100 USDT，同样的目标。这次小明打开了 Sentinel 的安全保护。」

**🖥️ 屏幕操作：**
- 勾选「🛡️ 穿上衣服再交易」
- 同样输入 100 USDT → USDC

**🎙️ 讲述：**
> 「系统开始把每条路都检查一遍——哪条路安全、哪条路有坑、哪条路最划算——然后全告诉你。」

**🖥️ 屏幕展示交易预览动画：**
```
┌─────────────────────────────────────┐
│  🔮 交易预言 · 看看你的钱会去哪    │
│                                     │
│  你的 100 USDT                     │
│       ↓                            │
│  ┌─ 走中国银行 ──── Route A ──┐   │
│  │  ✅ 这条路没问题             │   │
│  │  💰 到账：100.2 USDC         │   │
│  │  🏦 靠谱银行，天天有人走     │   │
│  └────────────────────────────┘   │
│                                     │
│  ┌─ 走招商银行 ──── Route B ──┐   │
│  │  ❌ 这家报价虚高，别去！     │   │
│  │  📉 到账：97.8 USDC（亏了）  │   │
│  └────────────────────────────┘   │
│                                     │
│  ┌─ 走贵峰银行 ──── Route C ──┐   │
│  │  ⚠️ 这家钱不够多            │   │
│  │    进去容易滑一大跤          │   │
│  └────────────────────────────┘   │
│                                     │
│  🛡️ AI 建议：走 Route A（中国银行）│
│  预期到账：100.2 USDC               │
│                                     │
│  [ ✅ 就走这条！]  [ 我再看看 ]     │
└─────────────────────────────────────┘
```

**🎙️ 讲述：**
> 「Route A——放心走，资金安全。Route B——就是刚才小明走的那条——Agent 发现这家报价虚高，直接拦下来了，还用大白话告诉你为什么。」

**🖥️ 点击「就走这条！」→ 交易成功：**
```
✅ 成了！
到账：100.2 USDC
比没穿衣服多拿了：2.4% 🎉
```

**🎙️ 讲述：**
> 「同样的金额，同样的目标。有 Sentinel 保护，到手 100.2 USDC；没有保护，只有 97.8 USDC。**差了 2.4%——不是运气问题，是你有没有人帮你扫坑。**」

## 附录：全剧大白话对照表

| 传统写法规格 | 大白话版 |
|-------------|---------|
| 交易执行中... | 🚀 正在检查路上有没有坑... |
| 报价偏离阈值 2.3% | ❌ 这条路报价虚高，别光着往里冲 🛡️ |
| 流动性不足 | 池子里钱不够，进去容易滑一大跤 |
| 合约未验证 | 这合约没穿衣服就跑出来了，先别碰 |
| 历史失败率 42% | 这条路 10 个人走 4 个翻车，咱换个走 |
| 自动切换至安全路径 | ⚠️ 前面有坑，已帮你拐到安全路线 ✅ |
| 推荐替代路径 | 换 Route A 吧，能多拿 39 USDC |
| 连接钱包 | 先拿出你的钱包 |
| 确认交易 | 点一下「就走这条！」 |
| 安全保护开启 | 🛡️ 穿上衣服再交易 |
| Gas 费 | 过路费 |
| 报价预期偏差 | 这家给的价不太对 |
| 风险评分 | 这条路靠谱程度 |
| 执行成功 | ✅ 成了！ |
| 交易预览 | 🔮 交易预言 · 看看你的钱会去哪 |

## 技术亮点

| 模块 | 实现方式 |
|------|---------|
| 链 | Monad 测试链（真实链上数据） |
| 代币/池 | 自部署测试币 + 交易池 |
| 风控 | 规则引擎 evaluateRoute() + AI 解释层 |
| 前端 | React + Vite，支持浅色/深色主题 |
| 钱包 | MetaMask 连接 |
| 成就 | NFT 勋章墙（mock 数据） |
| 语言风格 | 全篇大白话，菜市场阿姨都能听懂 🗣️ |
