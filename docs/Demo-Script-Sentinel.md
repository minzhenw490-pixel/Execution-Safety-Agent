# 🎬 Demo Script — Sentinel for Safe Execution

> **时长：** 约 3 分钟  
> **形式：** 开场小动画 + 现场操作讲解  
> **面向：** Hackathon 评委 / 观众  
> **定位：** 给 DeFi 小白用的交易安全助手  
> **详细：** 一个运行在 Monad Testnet 上的 Execution Safety Layer——多池报价、双层风险评估，决定放行或拦截
> **Slogan：** Don't trade naked. 🛡️  
> **语言风格：** 全篇大白话，菜市场阿姨都能听懂  
> **版本：** v5.0（无 X 光弹窗版）

---

## 🎬 场景设定

```
用户：小明
目标：把 100 USDC 换成 GOOD 代币
背景：Monad 测试链上有 3 个池子
        每个池子报价不一样
```

---

## 第一轮：没开保护 ❌

> **约 30 秒**

**🎙️：**
> 「小明想换点 GOOD 代币，随便选了个池子就冲了。」

**🖥️ 操作：**
- 打开页面，不勾选保护
- 输入 100 USDC → GOOD
- 点击「直接充」

**🖥️ 显示：**
- 到账：**97.8 GOOD**
- 弹出：「这条路池子太浅，滑了一大跤」

**🎙️：**
> 「到手少了 2.2%。问题是——发交易之前，没人告诉他这个池子有问题。」

---

## 第二轮：有 Sentinel 保护 · 池子有问题 🛡️

> **约 40 秒**

**🎙️：**
> 「同样的金额，这次打开 Sentinel。系统会怎么做？——先向多个池子要报价，然后一层一层检查。」

**🖥️ 操作：**
- 勾选「🛡️ 穿上衣服再交易」
- 输入 100 USDC → GOOD
- 点「检查一下」

**🖥️ 显示（检查结果）：**

```
🔍 正在检查 3 条路线...

路线 A · SAFE 池    报价 99.1 ✅
路线 B · SHALLOW 池 报价 100.5 ⚠️ 池子太浅
路线 C · TOXIC 池   报价 104.8 🔴 报价虚高

🛡️ 检测到：路线 C 报价比市场高 5%
   历史翻车率 42% · 疑似假深度池
   走这条路预计白亏 21%

建议：换 SAFE 池 → 到账 99.1 ✅
```

**🖥️ 点击「换 SAFE 池」→ 点「就走这条！」→ 成功：**

```
✅ 成了！
到账：99.1 GOOD
比走 TOXIC 多拿：16%
```

**🎙️：**
> 「TOXIC 池报价 104.8，看着最高——但系统发现这个池子有假深度，走进去实际只能拿到 83，白亏 21%。」
>
> 「换成 SAFE 池，到账 99.1。就多花两秒检查——到账多了 16%。」
>
> 「**这就是我们说的——最佳报价 ≠ 最佳路线。**报价高的那条路，可能恰恰是坑最深的那条。」

---

## 第三轮：代币本身也有问题 🪙

> **约 30 秒**

**🎙️：**
> 「不只池子有问题——有时候代币本身就有问题。同一个池子，换个 BAD 代币看看。」

**🖥️ 操作：**
- 重新输入 100 USDC → **BAD**
- 勾选保护 → 点「检查一下」

**🖥️ 显示：**

```
🔍 正在检查...

🪙 Token Risk 检测到问题：
❌ 该代币合约权限异常
❌ 历史交易记录存在可疑行为
❌ 已被标记为高风险资产

⚠️ 虽然池子本身是 SAFE 池，
   但代币 BAD 存在安全风险。
   建议不要进行这笔交易。

🛡️ 决策：REJECT（已拦截）
```

**🎙️：**
> 「池子是好的，但代币本身有问题——合约权限异常、历史记录可疑。系统直接拦截，不让这笔交易发生。」
>
> 「这就是第二层检查的意义——池子没问题，代币有问题，一样拦住。」

---

## 第四轮：滑点警告 ⚡

> **约 20 秒**

**🎙️：**
> 「还有一种情况——池子不是恶意的，就是太浅了。报价看着还行，但滑点高，到账就少了。」

**🖥️ 操作：**
- 重新输入 100 USDC → GOOD
- 手动选 **SHALLOW** 池
- 点「检查一下」

**🖥️ 显示：**

```
⚠️ 这条路报价正常，但池子太浅
   滑点偏高（16.8%）
   到账预计只有 83.12 GOOD

   建议换 SAFE 池 → 到账 99.1 ✅
```

**🎙️：**
> 「不是每条路都有毒，但有些路就是不太划算。系统也会告诉你——报价正常，但池子太浅，滑点高，到账就少了。换条路更划算。」

---

**🎙️：**

>

>
> 「交易越多，级别越高。就像在给盔甲慢慢升级。」
