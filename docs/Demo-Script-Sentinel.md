# 🎬 Demo Script — Sentinel for Safe Execution

> **时长：** 约 3 分钟  
> **形式：** 开场小动画 + 现场操作讲解  
> **面向：** Hackathon 评委 / 观众  
> **定位：** 给 DeFi 小白用的「交易安全助手」  
> **Slogan：** Don't trade naked. 🛡️  
> **语言风格：** 全篇大白话，菜市场阿姨都能听懂  
> **版本：** v4.0（Week 4 多池报价版）

---

## 🎭 开场（15 秒动画）

> **屏幕先全黑，然后播放一段像素风小动画**

（动画内容不变：小明从小变大、从裸到穿甲）

**🎙️ 动画结束后开口：**

> 「看到这个 Logo 了吗？外面是盾牌，里面是一只独角兽。」
>
> 「独角兽代表智慧、稀缺和未来感——它是咱们的 AI Agent。」
>
> 「Monad 链以高性能、高频交易著称。Sentinel 就是那个保持冷静判断的智能守护者。」
>
> 「我是 77，这是我们做的——**Sentinel。**」
>
> **「Don't trade naked.」**
>
> 「字面上别裸冲，金融里是裸持仓，心理上不想被割。交易前先穿好装备。」

---

## 🎬 场景设定

```
用户：小明
目标：把 100 USDC 换成 GOOD 代币
背景：Monad 测试链上有 3 个池子
        每个池子报价不一样
```

---

## 第一轮：没开保护 ❌

> **约 30 秒**

**🎙️：**
> 「小明想换点 GOOD 代币，随便选了个池子就冲了。」

**🖥️ 操作：**
- 打开页面，不勾选保护
- 输入 100 USDC → GOOD
- 点击「直接充」

**🖥️ 显示：**
- 到账：**97.8 GOOD**
- 弹出：「这条路池子太浅，滑了一大跤」

**🎙️：**
> 「到手少了 2.2%。问题是——发交易之前，没人告诉他这个池子有问题。」

---

## 第二轮：有 Sentinel 保护 🛡️

> **约 2 分钟**

**🎙️：**
> 「同样的金额，这次打开 Sentinel。系统不只是报价——它提前帮你模拟了一遍。」

**🖥️ 操作：**
- 勾选「🛡️ 穿上衣服再交易」
- 输入 100 USDC → GOOD
- 点「检查一下」

**🖥️ 屏幕 🔍 一闪（跟开场动画一样的扫描效果）→ 弹出：**

```
┌─────────────────────────────────────────┐
│  🔮 交易 X 光 · 看看你的钱会去哪       │
│                                          │
│  你输入：100 USDC → 走 TOXIC 池         │
│                                          │
│  ⚠️ 这个池子报价比市场高 5%             │
│  ⚠️ 历史翻车率 42%                       │
│  ⚠️ 疑似假深度池                          │
│                                          │
│  ┌─── 模拟结果 ──────────────────────┐  │
│  │  你以为会到账：104.8 GOOD          │  │
│  │  实际到账：    ❌ 83 GOOD          │  │
│  │  白亏：        💸 21%              │  │
│  └────────────────────────────────────┘  │
│                                          │
│  🛡️ 建议：换 SAFE 池 → 到账 99.1 ✅  │
│                                          │
│  [ ✅ 就走这条！]  [ 换一条路 ]         │
└─────────────────────────────────────────┘
```

**🎙️：**
> 「注意到那个 🔍 闪了一下吗？跟开场动画里一样。这就是独角兽在扫描——提前帮你看清楚这条路到底能不能走。」
>
> 「TOXIC 池报价看着最高——104.8。但系统模拟发现这个池子有假深度，走进去实际只能拿到 83，白亏 21%。」

**🖥️ 点击「换一条路」→ 自动切到 SAFE 池 → 点「就走这条！」→ 成功：**

```
✅ 成了！
到账：99.1 GOOD
比走 TOXIC 多拿：16%
```

**🎙️：**
> 「就多花两秒看个 X 光——到账多了 16%。不是运气问题，是你有没有人帮你提前扫一遍路。」

---

## 第三轮：代币本身也有问题 🪙

> **约 30 秒**

**🎙️：**
> 「不只池子有问题——有时候代币本身就有问题。我们试一下同一个池子，换一个 BAD 代币看看。」

**🖥️ 操作：**
- 重新输入 100 USDC → **BAD**
- 勾选保护 → 点「检查一下」

**🖥️ 显示：**

```
🔍 正在检查...

🪙 Token Risk 检测到问题：
❌ 该代币合约权限异常
❌ 历史交易记录存在可疑行为
❌ 已被标记为高风险资产

⚠️ 虽然池子本身是 SAFE 池，
   但代币 BAD 存在安全风险。
   建议不要进行这笔交易。

🛡️ 决策：REJECT（已拦截）
```

**🎙️：**
> 「注意——这次池子没问题，是代币本身有问题。Agent 不只查池子，还查代币。两层检查，两层保护。」
